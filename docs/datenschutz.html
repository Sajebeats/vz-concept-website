1. Datenschutz auf einen Blick

Allgemeine Hinweise

Die folgenden Hinweise geben einen einfachen Überblick darüber, was mit Ihren personenbezogenen Daten passiert, wenn Sie diese Website besuchen. Personenbezogene Daten sind alle Daten, mit denen Sie persönlich identifiziert werden können. Ausführliche Informationen zum Thema Datenschutz entnehmen Sie unserer unter diesem Text aufgeführten Datenschutzerklärung.

Datenerfassung auf dieser Website

Wer ist verantwortlich für die Datenerfassung auf dieser Website?
Die Datenverarbeitung auf dieser Website erfolgt durch den Websitebetreiber. Dessen Kontaktdaten können Sie dem Impressum dieser Website entnehmen.

Wie erfassen wir Ihre Daten?
Ihre Daten werden zum einen dadurch erhoben, dass Sie uns diese mitteilen – etwa durch das Buchen eines Termins über Calendly oder durch eine E-Mail-Kontaktaufnahme. Beim Seitenaufruf verarbeitet der Hosting-Anbieter außerdem technisch notwendige Verbindungsdaten. Der eingebettete Kalender wird erst nach einem bewussten Klick geladen.

Wofür nutzen wir Ihre Daten?
Wir verarbeiten Daten für die Bereitstellung der Website, die Bearbeitung Ihrer Anfragen und die Terminvereinbarung. Auf dieser Website sind derzeit keine Analyse- oder Werbetracking-Dienste aktiv.

2. Hosting

Diese Website wird über GitHub Pages bereitgestellt (Anbieter: GitHub Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA). Beim Aufruf der Website verarbeitet GitHub technisch notwendige Daten in Server-Logfiles, insbesondere IP-Adresse, Browser-Typ, Betriebssystem, Referrer-URL, Hostname und Datum/Uhrzeit der Serveranfrage.

Da GitHub seinen Sitz in den USA hat, kann eine Übermittlung personenbezogener Daten in die USA stattfinden. GitHub ist nach dem EU-US Data Privacy Framework zertifiziert und bietet damit ein angemessenes Datenschutzniveau (Art. 45 DSGVO). Rechtsgrundlage für die Verarbeitung ist Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse an einer technisch fehlerfreien Bereitstellung der Website).

Datenschutzerklärung von GitHub: github.com/de/site-policy/privacy-policies

4. Datenerfassung auf dieser Website

Schriftarten (Self-Hosted)

Diese Website nutzt die Schriftarten Inter, Playfair Display und Dancing Script. Die Schriftdateien werden zusammen mit der Website über GitHub Pages ausgeliefert. Dafür wird keine Verbindung zu Google Fonts oder anderen externen Schriftanbietern hergestellt.

Calendly (Terminbuchung)

Für die Terminvereinbarung nutzen wir Calendly LLC, USA. Der eingebettete Kalender wird erst geladen, wenn Sie „Kalender laden“ auswählen. Erst dann werden Verbindungen zu Calendly und den für den Kalender verwendeten Dienstanbietern hergestellt. Dabei können insbesondere IP-Adresse, Browser- und Gerätedaten verarbeitet sowie Cookies oder ähnliche Speichertechniken verwendet werden. Alternativ können Sie Calendly über den externen Buchungslink öffnen oder einen Termin per E-Mail anfragen.

Das freiwillige Laden des eingebetteten Kalenders erfolgt auf Grundlage Ihrer Einwilligung nach Art. 6 Abs. 1 lit. a DSGVO; für nicht erforderliche Zugriffe auf Ihr Endgerät gilt § 25 Abs. 1 TDDDG. Sie können die Einbettung durch Neuladen oder Verlassen der Seite beenden. Sie wird beim nächsten Aufruf erst nach erneutem Klick geladen. Die bis dahin erfolgte Verarbeitung bleibt davon unberührt.

Bei einer Buchung werden die eingegebenen Angaben, insbesondere Name, E-Mail-Adresse und Terminwunsch, für die Terminorganisation verarbeitet. Bei vertragsbezogenen Terminen ist die Rechtsgrundlage Art. 6 Abs. 1 lit. b DSGVO, bei sonstigen Anfragen Art. 6 Abs. 1 lit. f DSGVO mit dem Interesse an einer geordneten Bearbeitung. Daten können in den USA verarbeitet werden. Calendly erklärt seine Teilnahme am EU-US Data Privacy Framework und beschreibt weitere Übermittlungsgarantien in seinen Datenschutzhinweisen.

Aktueller Stand

Diese Website setzt aktuell keine eigenen Tracking-Cookies ein. Google Analytics 4, Google Ads und Meta Pixel sind nicht aktiv. Für lediglich geplante Dienste wird keine Einwilligung eingeholt. Informationen zum aktuellen Stand können Sie über „Cookie-Einstellungen“ im Seitenfuß aufrufen.

Technische Einstellungen

Soweit Sie eine technische Datenschutzeinstellung speichern, wird diese ausschließlich im lokalen Speicher Ihres Browsers hinterlegt. Sie dient der Umsetzung Ihrer Auswahl und wird nicht zur Wiedererkennung für Werbung verwendet. Für eine zur Bereitstellung der ausdrücklich gewünschten Funktion erforderliche Speicherung gilt § 25 Abs. 2 Nr. 2 TDDDG. Sie können lokale Website-Daten über die Einstellungen Ihres Browsers löschen.

Informationen in Kampagnenlinks

Wenn Sie über einen Kampagnenlink auf diese Website gelangen, kann dessen Adresse Herkunftsangaben wie UTM-Parameter oder eine Google-Klickkennung (gclid) enthalten. Vorhandene Parameter können über interne Links bis zur Terminbuchung und beim bewussten Öffnen des Kalenders an Calendly weitergegeben werden, um eine Anfrage ihrer Herkunft zuzuordnen. Dafür legt die Website keinen zusätzlichen Eintrag in Cookies oder im lokalen Browserspeicher an. Eine Klickkennung kann einen einzelnen Anzeigenklick zuordnen und ist daher nicht mit anonymen Daten gleichzusetzen.

Die Verarbeitung vorhandener Herkunftsangaben dient unserem berechtigten Interesse, die Herkunft von Anfragen nachzuvollziehen (Art. 6 Abs. 1 lit. f DSGVO). Die im Abschnitt „Widerspruchsrecht“ genannten Rechte gelten auch hierfür. Eine Buchung ohne diese Angaben ist über den direkten Calendly-Link ohne Kampagnenparameter oder per E-Mail möglich.

Soweit eine Einwilligung erforderlich ist, werden solche Dienste erst nach Ihrer ausdrücklichen Auswahl geladen. Name, E-Mail-Adresse oder Gesprächsinhalte werden nicht an Analyse- oder Werbetracking-Dienste übermittelt.
